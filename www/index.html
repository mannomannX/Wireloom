About Wireloom Studio

Wireloom is a lightweight, indentation-based text DSL for sketching and rendering static UI wireframe mockups as pure inline SVG.

🛠 Community Fork & Visual Sandbox

This web studio is an actively maintained community fork (Maintainer: mannomannX) of the original StardockCorp/Wireloom project by Brad Wardell (MIT License), forked in August 2026.

The studio serves as an interactive visual sandbox for rapid prototyping, exploring layout primitives, live formatting, and exporting high-fidelity vector SVGs and retina PNGs.
